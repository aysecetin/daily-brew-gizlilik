# Daily Brew — gizlilik politikası

Daily Brew mobil uygulamasının gizlilik politikası. GitHub Pages'ten yayımlanır:

- https://aysecetin.github.io/daily-brew-gizlilik/ — giriş sayfası
- https://aysecetin.github.io/daily-brew-gizlilik/gizlilik.html — politika (TR + EN)

Uygulamanın kendi deposu gizlidir; bu sayfa ayrı ve açık bir depoda durur çünkü
GitHub ücretsiz planda gizli depodan Pages yayını yapmaz, mağazalar ise
uygulamadan bağımsız erişilebilen bir adres ister.

Adres uygulamanın içinde `src/screens/SettingsScreen.tsx` dosyasındaki
`PRIVACY_URL` sabitinde geçer. **Dosya adı değişirse o sabit de değişmeli**,
yoksa Ayarlar'daki bağlantı 404 verir.

Metin uygulamadan bağımsız güncellenebilir: buradaki bir düzeltme mağaza
güncellemesi beklemeden yayına girer. Politikanın anlattığı davranış değişirse
yürürlük tarihi ve sürüm satırı da güncellenmeli.
